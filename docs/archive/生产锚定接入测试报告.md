## 1. 测试目标

验证 production WDL 概率锚定（读取 `model_predictions` 表 `WDL_home/WDL_draw/WDL_away` 生产模型输出）接入 T-006 v5 比分预测模块后：

1. **功能正确性**：生产锚定优先、无效/缺失自动回退去水赔率/默认均线，下游无侵入。
2. **性能校准**：严格 TimeSeriesSplit(5) 下，生产锚定变体 vs 去水变体的 Top-1/3/5 精确命中与 WDL 方向一致率。
3. **数据口径**：生产 WDL 覆盖场次、可回测场次、无赔率场次的真实分布。

## 3. 测试用例与结果

### 3.1 单元冒烟测试（predict_score_distribution 单测）

输入赔率 `win_a=2.10 / draw=3.40 / win_b=3.60`（去水后 [0.454, 0.281, 0.265]）。

| 用例 | 输入 | λ_home | λ_away | Top5 比分 | 判定 |
|------|------|--------|--------|-----------|------|
| 1a 纯去水基线 | 无生产锚定 | 1.775 | 0.825 | 1:1, 0:0, 1:0, 2:0, 2:1 | ✅ λ 正确 |
| 1b 生产锚定优先 | `[0.62, 0.22, 0.16]` | 2.075 | 0.525 | 2:0, 1:0, 1:1, 3:0, 0:0 | ✅ 锚定生效，λ 偏移到主队强 |
| 1c 无效锚定回退 | `[0, 0, 0]` | 1.775 | 0.825 | 与 1a 完全一致 | ✅ 无效输入安全回退 |
| 1d 无赔率+锚定 | `[0.60, 0.22, 0.18]`，wdl_history=None | 2.025 | 0.575 | 2:0, 1:0, 1:1 | ✅ 无赔率场次可锚定 |
| 1e 全缺省回退 | 无赔率无锚定 | 1.540 | 1.260 | — | ✅ 保持 v4 默认均线路径 |

**结论**：生产锚定优先级、归一化、无效回退逻辑全部正确；参数默认 `None` 对旧调用零影响。

### 3.2 端到端验证（analyze_match_score 全链路）

场次 `2026-08-22_Arsenal_Coventry City`（model_predictions 有生产 WDL）：

- 读取生产锚定：`[0.5311, 0.2335, 0.2354]` ✅
- 输出 top3：`2:0 (0.1119) → 1:1 (0.1111) → 1:0 (0.1050)` ✅
- `analyze_match_score` 在 conn 关闭前正确读取并传入锚定，全链路无异常。

**结论**：生产/回测入口自动生效，锚定缺失自动回退，无侵入下游。

### 3.3 v4 → v5 消融对比（基线验证，产物 t006_v5_ablation.json）

方法：`TimeSeriesSplit(n_splits=5, 无 shuffle)`，有赔率场次子集（去水 WDL 可解）。

| 指标 | v4 | v5 | Δ |
|------|-----|-----|----|
| Top-1 命中率 | 10.70% | **13.14%** | **+2.44pp** |
| Top-3 命中率 | 26.88% | **30.44%** | **+3.56pp** |
| Top-5 命中率 | 40.27% | **45.47%** | **+5.20pp** |
| WDL 方向一致率 | 71.37% | 71.25% | -0.12pp（不劣化） |

样本：n=7693（有赔率）；WDL 子样本 n=5715。

**结论**：v5 三个精确命中指标全线正向（Top-1 +2.44pp），WDL 一致率 -0.12pp 属波动范围，验证 IPF 重加权核心目标「不劣化 WDL 栈的前提下提升比分精确度」。

### 3.4 生产锚定对比回测（run_production_anchor_compare）

方法：`TimeSeriesSplit(n_splits=5, 无 shuffle)`，全量有比分场次（含无赔率场次），球队近期形态仅取该场之前（防泄漏）。

**全量口径（n=8713）**：

| 指标 | v5_de_vig（去水） | v5_prod（生产锚定） | Δ |
|------|------------------|--------------------|----|
| Top-1 命中率 | 12.74% | 12.74% | +0.00pp |
| Top-3 命中率 | 29.54% | 29.53% | -0.01pp |
| Top-5 命中率 | 44.37% | 44.35% | -0.02pp |
| WDL 方向一致率 | 70.83% | 70.82% | -0.01pp |

**锚定生效子集（n=18）**：

| 指标 | v5_de_vig（基线） | v5_prod（生产锚定） | Δ |
|------|------------------|--------------------|----|
| Top-1 命中率 | 11.11% (2/18) | 11.11% (2/18) | +0.00pp |
| Top-3 命中率 | 22.22% (4/18) | 16.67% (3/18) | **-5.55pp** |
| Top-5 命中率 | 33.33% (6/18) | 22.22% (4/18) | **-11.11pp** |
| WDL 方向一致率 | 60.00% (9/15) | 53.33% (8/15) | **-6.67pp** |

**结论（诚实报告）**：
- 全量口径两变体基本持平（Δ≤0.02pp），生产锚定未造成全库劣化。
- 锚定生效子集（n=18）显示 top3/top5/wdl 微劣化，但**样本极小、统计不显著**（1-2 场差异即 ±5.5pp），**当前不构成生产锚定显著增益证据**。

### 3.5 数据口径核查

| 检查项 | 结果 |
|--------|------|
| model_predictions 总行数 | 734 |
| 生产 WDL 三行齐全的场次数 | 53 |
| 与 matches 表可 join 的场次数 | 53（100%） |
| load_match_data（有比分）中带生产锚定的场次数 | 21 |
| 其中**有 wdl_history 赔率**的场次 | **0（全部无赔率）** |
| 严格时序 test 折内锚定生效场次数 | 18 |
| match_id_mapping 列名 | `sh_match_id / matches_match_id / match_method / confidence / created_at` |

**关键发现**：
- 53 场生产 WDL 全部为 2026-08+ 新场次，**无 wdl_history 赔率入库** → 原"有赔率子集"口径下锚定场次全部被跳过，故首次回测 anchored_subset n=0。
- 改全量口径（无赔率走默认均线回退）后，18 场锚定生效进入对比。
- 生产锚定的价值目前受**数据覆盖（53 场）与赔率入库滞后**双重限制，需持续运行 `generate_unified_report_v2.0` 累积。

## 4. 测试结论

| 目标 | 结论 | 状态 |
|------|------|------|
| 功能正确性 | 生产锚定优先、归一化、无效/缺失自动回退均正确；旧调用零侵入 | ✅ 通过 |
| 端到端链路 | analyze_match_score 全链路自动生效 | ✅ 通过 |
| 性能校准 | v4→v5 消融（n=7693）：Top-1 +2.44pp 等全线提升，WDL 不劣化 ✅；生产锚定全量持平（Δ≤0.02pp），锚定子集 n=18 显示微劣化但不显著 | ✅ / ⚠️ |
| 数据口径 | 53 场生产 WDL 全为无赔率新场次，可回测仅 18 场 | ⚠️ 覆盖受限 |

**总体判定**：生产锚定机制接入正确、安全（自动回退，不劣化），**当前保留"生产锚定优先但自动回退"设计**；因数据覆盖不足，暂不将其作为强制覆盖。待 model_predictions 覆盖扩大后复评。
