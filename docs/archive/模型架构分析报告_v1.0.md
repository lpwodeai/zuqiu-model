## 一、系统总览

本项目是一套**五大联赛（英/西/意/德/法）足球赛果预测全栈系统**，核心形态为 **「Python 训练离线侧 + Node.js 推理在线侧」的双运行时架构**：

- **训练/特征/回测**：Python（pandas/numpy/scipy + LightGBM/XGBoost/Optuna/sklearn），产出**双份模型产物**——pkl 供 Python 侧复用，JS 序列化供 Node.js 侧运行时加载（`convert_xgb_to_js`/`convert_lgb_to_js`）。
- **在线推理/服务**：Node.js（Express + WebSocket + better-sqlite3 + Redis），`PredictionService` 加载 `assets/*_export.js` 模型文件做内存推理，通过 `/api/predict` 系列端点对外服务。
- **数据中枢**：`data/odds.db`（SQLite，1.67GB，35 表），同时承载比赛事实（matches 14,572 场）、赔率时序（wdl/handicap/total_goals/score_history）、高级特征（sofascore_team_features 18,401 行/98 字段）、预测结果落库（model_predictions 625,741 行）与知识库闭环。

当前生产形态（2026-09-09 口径）：

| 维度 | 当前状态 |
|------|---------|
| WDL 主模型 | **254 维** LightGBM/XGBoost（`slim_odds + ts_odds + consensus_odds + 球员 lag/其他全量特征`），Stacking = 5 基础模型 + LR meta-learner（OOF RPS 0.1984）；训练↔服务端 254 维 CI 强制对齐 + feature_bridge 桥接 110 维真实值（C-20260910-004/011）；最新资产 `*_20260908_004604` |
| T-005 | v3 生产（`t005v3_direction_predictor.pkl` + `t005v3_draw_detector.pkl`，71 维），让球/方向预测 |
| T-006 | **v5 生产**（`score_prediction_module.py` 集成 + 生产 WDL 锚定）：严格时序 5 折 Top-1 10.70%→13.14%，Top-3 26.88%→30.44%，Top-5 40.27%→45.47%，WDL 方向不劣化；生产锚定读 model_predictions WDL_home/draw/away（缺失回退去水）（C-20260908-022/023/024） |

| 工程化 | MLflow（D1）、模型版本管理（D2）、config.yaml 单一来源（D3）、西甲赔率自动采集（D4）均已闭环（C-20260909-002~005）；P0-E 每日六步编排自动化（C-20260910-007）；P1-B 贝叶斯增量 shadow 每日滚动（C-20260911-017~025） |

### 3.3 训练层

⑤ evaluate_with_time_series_split (5 折时序, 802 行)

### 6.2 概率校准策略

- **Platt Scaling**（`train_models.py:595 fit_platt_scaling`）：验证集上拟合一元逻辑回归将原始概率映射到校准概率；产物 `assets/xgb_calibration_params.js` / `lgb_calibration_params.js`（仅 238 字节）。
- **平局后处理校准**（train_models.py 1067 行起）：自适应精细搜索，在 **平局召回率 ≥ 0.28** 约束下最大化准确率，候选为 Threshold（factor 1.00~2.50）与 DrawCalibrator（factor 0.50~1.00），Threshold 优先、DrawCal 需准确率高出 ≥0.5pp（1206 行）。校准结果写入 `draw_calibrator_params_{ts}.json`。

### 6.3 draw_threshold 机制（config.yaml:283-298）

- 语义：**不修改概率，只调整分类决策**。`factor<=0 或 =1.0` 等价 argmax；`0<factor<1` 反压低平局（抬高平局门槛）；`factor>1` 上浮平局。
- 当前全局 `draw_threshold_mode: argmax`（290 行），逐联赛因子保留（293-298 行，C-20260820-037 校准）：西甲 0.80(+1.05pp) / 意甲 0.85(+0.97pp) / 德甲 0.85(+0.87pp) / 英超·法甲 argmax。
- 训练侧：`train_models.py:576 apply_draw_threshold(probs, factor)`；推理侧：`prediction-service.js:498 applyLeagueDrawThreshold`（`drawBoosted = draw * factor`，> max(win,lose) 判平局）。
- **D3 已闭环**：JS 因子表硬编码已移除，运行时读 config.yaml（prediction-service.js:43,95-127），单测 21/21 通过（C-20260909-004）。

### 6.4 比分预测 T-006 v5（t006_score_predictor_v5.py）

v5 相对 v4 的两大核心改进（`predict_score_distribution_v5` 145 行）：

1. **λ 数值求解**（`solve_lambda_core` 80 行）：对去水 WDL 概率，用二分法（45 次迭代，d∈[-2,2]）求解强度差 d，使泊松胜负倾向 `(Pwin_home - Pwin_away)` 精确对齐 WDL，替代 v4 的 `λ=2.8×胜率` 启发式。总进球期望由 `total = 0.5×2.6 + 0.5×min(4.5, max(2.0, tg_expected))`（156 行）融合。
2. **IPF 乘性重加权**（`ipf_reweight` 109 行）：30 轮迭代，按 home/draw/away 三个边缘依次乘性缩放比分网格，使 WDL 三边缘**构造性精确对准**目标概率（保证不劣化 WDL 栈）。DC τ 修正采用 λ 缩放版（`dc_tau` 55 行：`1.0 - lh*la*rho` 等）。

生产集成（`score_prediction_module.py`）：`production_wdl_probs` 锚定——优先读 `model_predictions` 的 WDL_home/draw/away（212 行），缺失回退去水赔率（136-143 行）。验收：Top-1 10.70%→13.14%、Top-3 26.88%→30.44%、Top-5 40.27%→45.47%，WDL 方向一致率 71.37%→71.25%（-0.12pp 不劣化，C-20260908-022/023/024）。产物已全量落库 623,887 行 / 14,509 场 100%（D-020）。

### 6.5 Dixon-Coles 体系

- 统一引擎 `unified_prediction_engine.py`：`_dc_correction`（87）对 (0,0)/(0,1)/(1,0)/(1,1) 施加 `1±ρ`；联赛 ρ 表（51-54 行）。
- 高级训练器侧：`advanced_model_trainer.py` 的 `_build_score_matrix`（1397）/`_inject_tail_anchors`（1436，λ_sum>2.2 或 λ_diff>0.5 时注入高比分/大分差锚点，config `score_matrix_tuning`）+ `_conditional_rerank`（1538，条件重排保 WDL 边缘）。
- `config.yaml unified_engine.dixon_coles.leagues`：英-0.08/西-0.12/意-0.15/德-0.05/法-0.10（476-480 行）。

### 6.6 让球/方向预测（T-005）

- `handicap_line_inference.py`（23KB）：让球盘口推断；`train_hcp_model_v2.py`：让球标签扩展（C3，走水样本 242→扩展，准确率 >51.7% 验收通过）。

### 6.7 EV 期望值引擎（ev_engine.py）

- `calc_ev`（206）：`EV = p_model×(odds-1) - (1-p_model)`
- `calc_edge`（216）：`p_model - p_market`（去水后市场概率）
- `calc_kelly`（225）：full/half/quarter 策略 + cap 裁剪
- `make_decision`（262）：EV>阈值(0.02) 且 edge>0 → VALUE；EV>0 且 edge>0 → MARGINAL；否则 AVOID
- **现状**：严格时序 OOF 平注 ROI -3.71%~-5.41%，edge 分桶非单调；概率/训练(EV-loss/MOD/Penalty)/数据/决策(收缩+分段)/换市场/RL 六层已证伪（C-20260904~09-05），转实盘小注验证（C1，`live_trial_away_favorite.py`，客胜≤2.5、EV>0、¥20 平注、300 注停止）。

### 6.8 样本权重体系（训练侧）
