## 数据库表结构参考

### matches 表
| 字段 | 类型 | 说明 |
|-----|------|------|
| match_id | TEXT | 比赛唯一标识 |
| home_team | TEXT | 主队名称 |
| away_team | TEXT | 客队名称 |
| match_date | TEXT | 比赛日期 |
| match_time | TEXT | 比赛时间 |
| league | TEXT | 联赛名称 |
| round | INTEGER | 轮次 |
| status | TEXT | 比赛状态 |

### wdl_timing 表（胜平负赔率时序）
| 字段 | 类型 | 说明 |
|-----|------|------|
| match_id | TEXT | 比赛ID |
| timestamp | TEXT | 发布时间 |
| win_a | REAL | 胜赔率 |
| draw | REAL | 平赔率 |
| win_b | REAL | 负赔率 |

### handicap_timing 表（让球赔率时序）
| 字段 | 类型 | 说明 |
|-----|------|------|
| match_id | TEXT | 比赛ID |
| timestamp | TEXT | 发布时间 |
| handicap | INTEGER | 让球数 |
| hcp_win | REAL | 让球胜赔率 |
| hcp_draw | REAL | 让球平赔率 |
| hcp_lose | REAL | 让球负赔率 |

### score_timing 表（比分赔率时序）
| 字段 | 类型 | 说明 |
|-----|------|------|
| match_id | TEXT | 比赛ID |
| timestamp | TEXT | 发布时间 |
| score | TEXT | 比分（X:Y） |
| odds | REAL | 赔率 |

### total_goals_timing 表（总进球赔率时序）
| 字段 | 类型 | 说明 |
|-----|------|------|
| match_id | TEXT | 比赛ID |
| timestamp | TEXT | 发布时间 |
| goals_0 | REAL | 0球赔率 |
| goals_1 | REAL | 1球赔率 |
| goals_2 | REAL | 2球赔率 |
| goals_3 | REAL | 3球赔率 |
| goals_4 | REAL | 4球赔率 |
| goals_5 | REAL | 5球赔率 |
| goals_6 | REAL | 6球赔率 |
| goals_7_plus | REAL | 7+球赔率 |

### match_results 表（比赛结果）
| 字段 | 类型 | 说明 |
|-----|------|------|
| match_id | TEXT | 比赛ID |
| actual_score | TEXT | 实际比分 |
| actual_wdl | TEXT | 胜平负结果 |
| actual_handicap | TEXT | 让球结果 |
| actual_total_goals | INTEGER | 总进球数 |

## 导入工具说明

### 主要工具文件

| 文件 | 说明 |
|-----|------|
| `reusable_import.py` | 核心导入函数，支持单场比赛导入 |
| `batch_import.py` | 批量导入脚本，支持多场比赛导入 |
| `import_log.md` | 导入日志文档，记录所有导入历史 |

### 使用方法

1. **单场导入**: 使用 `reusable_import.py` 中的 `import_match()` 函数
2. **批量导入**: 在 `batch_import.py` 的 `MATCHES_DATA` 列表中添加比赛数据，运行脚本
3. **日志查看**: 查看 `import_log.md` 获取导入历史和数据统计
