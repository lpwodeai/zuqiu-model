## 二、数据存储结构

赔率时序数据统一存储在 SQLite 数据库 `data/odds.db` 中，核心包含 **4 张时序表** + **1 张桥接表**：

```
data/odds.db
├── matches              -- 比赛基本信息（英文队名）
├── wdl_history          -- 胜平负赔率时序
├── handicap_history     -- 让球赔率时序
├── total_goals_history  -- 总进球赔率时序
├── score_history        -- 比分赔率时序
├── match_id_mapping     -- 中英 match_id 桥接表（sh_match_id → matches_match_id）
├── team_mapping         -- 球队中英名称映射
└── import_log           -- 导入日志
```

## 三、数据字段说明

### 通用字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `match_id` | TEXT | 比赛标识，中文格式 `日期_主队_客队`（如 `2024-05-19_曼城_西汉姆`） |
| `match_id_en` | TEXT | 比赛标识，英文格式（score_history 无此列，仅走桥表） |
| `timestamp` | TEXT | 赔率快照时间点（ISO 格式），每场平均约 5.2 个快照 |

---

### 3.1 胜平负赔率 `wdl_history`

- **覆盖场次**：约 12,575 场
- **对齐率**：98.3%（双通道合并）
- **玩法**：竞彩胜平负（主胜 / 平局 / 客胜）

| 字段 | 类型 | 说明 |
|------|------|------|
| match_id | TEXT | 比赛标识（中文） |
| match_id_en | TEXT | 比赛标识（英文） |
| timestamp | TEXT | 赔率快照时间点 |
| win_a | REAL | 主胜赔率（主队胜） |
| draw | REAL | 平局赔率 |
| win_b | REAL | 客胜赔率（客队胜） |

**派生特征**（由 `temporal_features.py` 计算）：
- `wdl_{win_a/draw/win_b}_open`：开盘赔率（首时点）
- `wdl_{col}_close`：收盘赔率（末时点）
- `wdl_{col}_change`：赔率变化值（初盘 - 终盘）
- `wdl_{col}_percentage_change`：变化百分比
- `wdl_{col}_trend_strength`：下降趋势强度
- `wdl_implied_prob_home/draw/away`：归一化隐含概率
- `wdl_market_signal`：市场预期信号（0=客胜, 1=平局, 2=主胜）
- `wdl_odds_confidence`：赔率分析置信度

---

### 3.2 让球赔率 `handicap_history`

- **覆盖场次**：约 13,125 场
- **玩法**：竞彩让球胜平负

| 字段 | 类型 | 说明 |
|------|------|------|
| match_id | TEXT | 比赛标识（中文） |
| match_id_en | TEXT | 比赛标识（英文） |
| timestamp | TEXT | 赔率快照时间点 |
| hcp_win | REAL | 让球主胜赔率 |
| hcp_draw | REAL | 让球平局赔率（让平） |
| hcp_lose | REAL | 让球客胜赔率（让负） |

**派生特征**：
- `hcp_{col}_open`：开盘赔率
- `hcp_{col}_change`：赔率变化值
- `hcp_prediction`：让球预测（-1=让负, 0=让平, 1=让胜）

---

### 3.3 总进球赔率 `total_goals_history`

- **覆盖场次**：约 13,126 场
- **玩法**：竞彩总进球数（0~7+ 球）

| 字段 | 类型 | 说明 |
|------|------|------|
| match_id | TEXT | 比赛标识（中文） |
| match_id_en | TEXT | 比赛标识（英文） |
| timestamp | TEXT | 赔率快照时间点 |
| goals_0 | REAL | 0 球赔率 |
| goals_1 | REAL | 1 球赔率 |
| goals_2 | REAL | 2 球赔率 |
| goals_3 | REAL | 3 球赔率 |
| goals_4 | REAL | 4 球赔率 |
| goals_5 | REAL | 5 球赔率 |
| goals_6 | REAL | 6 球赔率 |
| goals_7_plus | REAL | 7 球及以上赔率 |

**派生特征**：
- `tg_{col}_change`：各进球数赔率变化值
- `tg_target_goals_count`：目标进球数数量（优先级>0.3）
- `tg_low_goals_decrease`：低进球数（0-3球）赔率是否下降
- `tg_high_goals_decrease`：高进球数（4+球）赔率是否下降

---

### 3.4 比分赔率 `score_history`

- **覆盖场次**：约 13,122 场 / 816,026 行
- **对齐率**：63.8%（仅走桥表，无 match_id_en 列）
- **玩法**：竞彩正确比分

| 字段 | 类型 | 说明 |
|------|------|------|
| match_id | TEXT | 比赛标识（中文，无 match_id_en） |
| timestamp | TEXT | 赔率快照时间点 |
| score | TEXT | 具体比分（如 "2:1"、"1:0"） |
| odds | REAL | 该比分对应的赔率 |

**派生特征**：
- `score_target_{1..N}_diff`：目标比分主客差
- `score_target_{i}_change`：目标比分赔率变化
- `score_home_win_decrease_count`：主胜比分赔率下降数量

---

### 3.5 桥接表 `match_id_mapping`

用于解决时序表（中文队名）与 matches 表（英文队名）之间的 ID 映射问题。

| 字段 | 说明 |
|------|------|
| sh_match_id | 时序表中的中文 match_id |
| matches_match_id | matches 表中的英文 match_id |

**对齐策略**（6 种，按优先级）：
1. `cn_to_en`：通过 team_mapping 逐字段翻译
2. `substring`：子串模糊匹配
3. `direct`：直接等值匹配
4. `sofascore`：SofaScore 外部 ID 桥接
5. `fuzzy_date`：日期模糊匹配
6. `date_tolerance`：日期容差匹配（±1天）

## 四、关键数据链路

### 4.1 双通道对齐机制

```
时序表 match_id (中文)
    ├── 通道1: match_id_en 列直接匹配  → 覆盖 77.3%
    └── 通道2: match_id_mapping 桥表   → 覆盖 95.0%
    合并覆盖率: 98.3%
```

### 4.2 时序特征语义

特征层对每张时序表统一计算以下维度：
- **开盘赔率**：第一个时间点的赔率值
- **收盘赔率**：最后一个时间点的赔率值
- **赔率漂移**：初盘 - 终盘（正值=赔率下降，市场看好）
- **变化率**：(初盘-终盘)/初盘×100
- **趋势强度**：下降周期占比
- **隐含概率**：归一化后的 1/odds
- **市场信号**：融合隐含概率(70%) + 赔率变化趋势(30%)

### 4.3 采集频率与覆盖

| 数据类型 | 采集方式 | 频率 | 覆盖范围 |
|---------|---------|------|---------|
| 竞彩胜平负/让球/总进球/比分 | `supplement_sporttery_odds.py` | 历史回采（已完成） | 16/17~25/26 赛季 100% |
| 竞彩当日赛程 | `sporttery_live_collector.py` | 每 2 小时 | 26/27 赛季滚动 |
| 500.com 欧指/亚盘 | `final_500_collector.py` | `--refresh-odds` 滚动 | 历史+当日 |
| SofaScore 特征 | `final_sofascore_collector.py` | 按需 | 五大联赛 |
| Understat xG | `final_understat_collector.py` | 按需 | 五大联赛 |

### 4.4 回测口径

- **训练特征赔率源**：竞彩 `wdl_history` 末条快照（含抽水约 13%）
- **回测市场源**：`odds500_ouzhi_summary.avg_live`（500.com 百家欧指收盘均价，含抽水约 5.4%）
- **水位差注意**：两源系统性水位差需在归因/回测中校正

## 五、数据校验规则

| 校验项 | 规则 |
|--------|------|
| 赔率值有效性 | 所有赔率必须 > 1 |
| 隐含概率和 | WDL 隐含概率之和须在 [0.8, 1.3] 范围内 |
| 数据完整性 | 每场比赛至少 2 个时间点方可提取时序特征 |
| 必填字段 | match_id、timestamp、各玩法赔率字段不得为空 |
| 对齐完整性 | wdl/handicap/total_goals 对齐率 ≥ 95%，score ≥ 60% |
