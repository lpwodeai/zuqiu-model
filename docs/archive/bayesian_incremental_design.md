## 一、背景与目标

报告 v2.0 将「贝叶斯增量底座」列为 P1 中长期项，现状为：

> 仅 Stacking 第 5 基模（RPS 0.2092）；球队实力全量重训刷新

核心矛盾：当前贝叶斯层级模型每次刷新都**全量重训**（对所有历史比赛从头拟合 MAP），
没有「后验携带 + 增量更新」机制。本方案评估从「全量重训」迁移到
「增量更新 attack/defense 后验」的技术路线、并行对照设计与风险，**不落地代码**。

目标拆解（对齐报告 §P1-B 两阶段）：

|------|------|------|:----------:|
| 阶段 1 | 打磨基模 | 现状诊断 + 超参基线 | 现状分析（§二） |
| 阶段 2 | 增量更新 attack/defense 后验 | 技术路线 + 对照设计 | 路线设计（§三/§四） |

## 二、阶段 1：基模现状分析

### 2.1 现状实现（`bayesian_hierarchical_model.py`）

| 维度 | 现状 |
|------|------|
| 模型族 | Baio & Blangiardo (2010) 层级模型 + Dixon-Coles τ 修正 |
| 拟合方式 | **MAP 点估计**（scipy L-BFGS-B），非完整后验采样 |
| 后验近似 | **Laplace 对角近似**（`attack_std` / `defense_std`），仅攻防参数对角海森 |
| 刷新方式 | **全量重训**：每次 `fit()` 对所有历史比赛重跑优化，无后验携带 |
| 时间窗 | 指数时间衰减权重（`time_decay_half_life=300` 天，`min_weight=0.15`）近似赛季内随机游走 |
| 收缩先验 | `attack_i ~ N(0, σ_att²)`、`def_i ~ N(0, σ_def²)`（升班马自动收缩到联赛均值） |
| 参数规模 | `3 + 2×T`（μ、home_adv、ρ + 每队 attack/defense） |
| 切分 | 时间序列 80/20，无随机 shuffle（防泄露） |
| 集成位置 | Stacking 第 5 基模（`prediction_core.load_bayesian_model` 按联赛加载 `bayesian_model_{league}.json`） |

### 2.2 阶段 1 诊断结论

1. **Laplace 对角是近似而非完整后验**：只取海森对角（`_laplace_std`），忽略 attack/defense
   之间的 off-diagonal 相关。作为「增量更新的先验」直接复用会低估真实不确定性。
2. **时间衰减是「软性」随机游走**：`min_weight=0.15` 意味着旧比赛仍贡献 ≥15% 权重，
   不是真正的遗忘/状态转移。增量化的状态转移方差需重新标定。
3. **升班马/新队**：`attack=0` 初始 = 联赛均值，层级先验自然收缩——这是增量方案的
   「冷启动」关键约束，增量侧必须保留。
4. **全量重训成本**：5 联赛各 retrain 一次 L-BFGS-B（各约几十～几百参数），
   单次秒级～分钟级。**增量化的核心价值不在省钱，而在「更贴近期末状态的连续后验」**，
   需在对照中用指标证明，而非默认其更优。

## 三、阶段 2：增量更新攻击/防守后验的技术路线

### 3.1 候选方案矩阵

| 方案 | 原理 | 优点 | 缺点 | 推荐度 |
|------|------|------|------|:------:|
| **A. 后验携带 warm-start MAP** | 上一期后验（均值+方差）作为新先验，新窗口数据下重新 MAP | 改动最小、复用现有 `_neg_log_posterior` | 仍是点估计，先验方差是 Laplace 对角近似 | 兜底 |
| **B. 状态空间 + Kalman 滤波** | `attack_i,t ~ N(attack_i,t-1, τ²)` 随机游走 + Poisson 观测，EKF/UKF 序贯更新 | 显式转移动态、连续后验、天然适配"球队实力随时间演化" | 需线性化（EKF）或粒子；多队联合观测需同步更新 | **首选** |
| **C. 变分贝叶斯 / SVI** | 完整后验 VI，mini-batch 序贯更新 | 最稳健、量化完整不确定性 | 实现与诊断复杂度高，收益需对照证明 | 研究性 |

### 3.2 推荐路线：B（Kalman）为主，A（warm-start MAP）为兜底

理由：
1. 项目既有 Elo 时序经验与用户侧「Kalman 滤波状态估计」方法论沉淀一致；
2. Kalman 天然把「后验均值 + 方差」作为下期先验，正是报告 P1-B 的
   「增量更新 attack/defense 后验」字面要求；
3. 观测模型是 Poisson(log-link)，与现状 `log(λ)=μ+home+att−def` 一致，EKF 线性化
   代价小、后续可升级 UKF。

### 3.3 状态方程与观测方程（B）

```
状态转移（每轮刷新）:
    attack_i,t = attack_i,t-1 + ε_att,  ε_att ~ N(0, τ_att²)
    defense_i,t = defense_i,t-1 + ε_def, ε_def ~ N(0, τ_def²)

观测（每场进球，Poisson log-link）:
    log(λ_home) = μ + home_adv + attack_home,t − defense_away,t
    log(λ_away) = μ + attack_away,t − defense_home,t
    goals_home ~ Poisson(λ_home),  goals_away ~ Poisson(λ_away)
```

- `τ_att²` / `τ_def²` 是**状态转移方差**（新超参，需在阶段 1 网格标定），
  与现状 `σ_att=0.35`/`σ_def=0.35` 的**层级先验方差**区分。
- 新队冷启动：`attack=0`、`P=σ_init²`（=联赛均值 + 大方差），保留层级收缩语义。

### 3.4 关键设计约束（增量侧必须满足）

1. **严格时间序贯**：只能按 `match_date` 顺序吸收比赛，禁止用未来数据更新先验。
2. **新队不回放历史**：升班马从联赛均值先验起步，不与老队混用同一转移动态。
3. **Dixon-Coles ρ 与 home_adv/mu**：可维持全局低频更新（每 N 场重估），
   不必逐场转移（这几项跨队共享、变化慢）。
4. **不确定性出口**：保留 `attack_std`/`def_std`，供 Stacking 下游做
   「低置信收缩」或报告输出（与 Laplace 对角线语义兼容）。

## 四、并行对照设计（门禁）

增量方案**不得直接替换全量重训**，必须与全量重训做「同数据、同切分」的未来样本对照。

### 4.1 对照协议

| 项 | 全量重训（基线 A） | 增量更新（实验 B） |
|----|-------------------|-------------------|
| 训练输入 | 截至 t 的全部历史 | 截至 t-1 的后验 + 新窗口比赛 |
| 预测目标 | t+1 未来样本 | t+1 未来样本（**同一批**） |
| 切分 | 严格时间序列 | 严格时间序列 |
| 指标 | RPS / LogLoss / Acc / DrawRecall | 同左 |
| 显著性 | 未来样本 n≥60 后两比例 z + McNemar / 配对 bootstrap | 同左 |

### 4.2 门禁判据（对齐 C-20260910-008 四指标口径）

- RPS 不劣化（增量 RPS ≤ 全量 RPS + ε，ε≈0.002）
- LogLoss 不劣化（+ε≈0.01）
- Accuracy 稳定（±1.0pp 内）
- DrawRecall 不降（−1.0pp 内）
- 全部门禁 PASS 才允许增量进入 shadow 并行；shadow 稳定后再议生产切换。

### 4.3 分阶段验收

1. **离线单联赛试点**：先在意甲/西甲（样本较足）跑通对照，四指标达门禁；
2. **五联赛扩展**：确认升班马冷启动不劣化；
3. **shadow 并行**：与现状全量重训双跑 N 轮，观察连续后验稳定性；
4. **生产切换判据**：未来样本显著不劣化 + 后验对「实力突变」（换帅/伤病）响应更快。

## 五、风险点与缓释

| # | 风险 | 影响 | 缓释 |
|---|------|------|------|
| 1 | **后验坍缩**：τ 设太小 → 新数据难撼动旧后验，失去对战状态敏感性 | 模型对新近实力变化麻木 | τ 在阶段 1 网格标定，并监控后验 effective sample size |
| 2 | **冷启动偏差**：升班马无历史，转移动态与老队混用 | 新队实力估计偏差 | 新队独立先验（联赛均值 + 大方差），不回放 |
| 3 | **Laplace 对角低估不确定性**：作先验时方差偏窄 | 过度自信 | 引入 inflation 系数（≥1.0）放大先验方差；或改用 Kalman 的 P 协方差 |
| 4 | **概念漂移**：换帅/伤病导致实力阶跃，随机游走难捕获 | 阶跃后数场预测偏差 | 富 event 型触发重估 τ 或跳变检测（衔接 P0-C 概念漂移门禁） |
| 5 | **切分泄露**：增量实现若不严格时序 | 指标虚高、门禁失效 | CI 加时序不变性测试（shuffle 必须 FAIL） |
| 6 | **收益边际**：全量重训已 cheap，增量收益可能为 0 | 徒增复杂度 | 对照若无法证明显著不劣化/更快，则维持全量重训（**可回滚判定**） |

## 六、实施触发条件（明确「不提前实施」）

本方案**仅评估，不实施**。触发实施需同时满足：

1. P0 全部落定（尤其 P0-E 实盘 300 注完成）；
2. P0-A 复盘样本累积使 Stacking 基模评估具备足够未来样本（n≥60/联赛）；
3. 团队确认「连续后验」对实力变动的响应速度是当前 Stacking 的实测量化瓶颈。

在触发前，阶段 1 可选项（**若需要，单独确认后**）：
- 现状 MAP 超参网格（`σ_att`/`σ_def`/`time_decay_half_life`）做一次基线标定，产出各联赛基线表，供未来对照锚定。
