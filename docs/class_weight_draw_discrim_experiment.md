### 1.3 豁免理由（与 9 组网格证伪的差异）

9 组网格证伪的是「抬 `p_draw` 均值 / 召回」；本次目标与历史证伪**目标不同**：

| 历史证伪目标（禁令） | 本次实验目标 |
|---|---|
| 抬平局**均值**（`p_push_mean`） | 抬平局**判别力 AUC**，且均值偏差 |Δ| ≤ 2pp 不带动 |
| 抬平局**召回**（无约束） | 召回 ≥ 0.30，但**门禁④**专门防校准带偏（`p_draw` 均值偏差 |Δ| ≤ 2pp） |

门禁④即是为本次实验划界而设——一旦候选 ratio 把 `p_draw` 均值抬到偏离实际走水率超过 2pp，即视为「重蹈历史证伪覆辙」，自动判负。

实验出现以下任一情况，**豁免自动收回**，禁令恢复原状，候选 pkl 应归档删除：

## 3. 四门禁规则（用户修订版）

### 3.1 门禁清单

| 门禁 | 指标 | 阈值 | 备注 |
|---|---|---|---|
| ① 判别力 | fresh 窗口 AUC（`p_draw` vs `y==1`） | ≥ 0.68 | n ≥ 300 才正式裁决，n < 300 只作方向参考 |
| ② 走水均值偏差 | \|`p_push_mean` − `push_actual_rate`\| | ≤ 2pp | 与 drawfix 上线约束一致 |
| ③ 走水召回 | `push_recall` | ≥ 0.30 | 与 drawfix C-002 协议一致 |
| ④ 校准不带动 | 候选 `p_draw` 均值偏差 \|Δ\| vs 基线 | ≤ 2pp | **防带偏校准**（本次证伪换来的新增门禁） |

### 3.2 门禁④语义

门禁④是本次实验的核心护栏。其语义：

- 基线 = 生产 `t005v3_draw_detector.pkl` + `t005v3_draw_calibrator.pkl` 在 fresh 窗口的 `p_draw` 均值；
- 候选 = `class_weight ∈ {1.5, 2.0, 2.5, 3.0}` 重训 pkl + iso 校准器在 fresh 窗口的 `p_draw` 均值；
- 通过条件：候选 `p_draw` 均值与基线偏差 |Δ| ≤ 2pp。

如果门禁①通过但门禁④未通过 → 说明判别力提升是靠**整体抬平局概率**换来的（即重蹈历史证伪覆辙），判负。

### 3.3 门禁触发时序

```
fresh n < 300  →  只看方向参考，不触发任何切换决策
fresh n ≥ 300  →  四门禁同时评估
                  ├─ 全部通过  →  证真，登记 change_log，提交切换 PR
                  ├─ 任一未通过  →  证伪，登记 change_log，豁免自动收回
                  └─ 门禁①通过 / 门禁④未通过  →  特别登记「判别力↑但靠抬均值」的反例
```

### 4.3 JOIN 口径（评测时）

评测脚本 `scripts/class_weight_shadow_eval.py` 按 `match_id` JOIN：
- 赛果表：`post_match_review.actual_handicap`（0上/1走/2下）；
- 兜底：`matches.actual_handicap`（解析 `"(±d)胜/平/负"` 文本，提取 H 线位）；
- 与 `shadow_jsonl_eval.py` 同口径（match_id 去重覆盖、不现场重算）。

### 4.4 评测指标

对每个 `class_weight_version` 计算：
- **AUC**（`p_draw_marginal` vs `y==1`，二分类 roc_auc_score）
- **走水均值偏差**（`p_draw_marginal.mean()` vs `y==1` 实际率）
- **走水召回**（argmax_class==1 命中率）
- **门禁④ Δ**（候选 `p_draw_marginal.mean()` − control `p_draw_marginal.mean()`）

### 4.5 两开关 staging

`active:true`（训练守门）→ 网格重训落盘 4 候选 → **冒烟**（1-2 场 replay：生产报告内容逐字节一致【生成时间戳字段除外】+ jsonl schema/去重正确）→ `shadow_enabled:true`（当晚 20:30 生产链起积累）。**冒烟失败则 shadow 保持 false，生产链零影响**。

## 5. 统计功效声明

### 5.1 SE 口径（红线拥有者拍板原始数）

**fresh n=300、平局样本 ~48-51 时，AUC 的 SE≈0.05（Hanley-McNeil 复核 ≈0.045）。**

计算依据：
- fresh 评估窗平局样本数 ≈ 48-51（fresh n=300 × 走水率 16-17%）；
- Hanley-McNeil AUC 方差代入 n_pos≈48-51、n_neg≈249-252、AUC≈0.65 → SE ≈ 0.045，取保守口径 **SE≈0.05**。

（本节此前误写 SE≈0.07，统一回红线拥有者拍板的原始口径 SE≈0.05。2026-10-13 补钉）

### 5.2 功效含义

- 本次证伪结论（AUC 0.632、t=0.30 阈值净负）**有效**——证伪用弱证据就够；
- **证真**需要强证据：AUC 0.632 → 0.68 的目标差 0.048 ≈ **1 个 SE**（SE≈0.05）；
- 因此：**fresh n ≥ 300 之前，门禁指标（含 AUC ≥ 0.68）只作方向参考，不构成通过**。（2026-10-13 补钉）

### 5.3 噪声带护栏

门禁① 在 fresh n < 300 时即使 AUC ≥ 0.68 也不触发通过；必须等 n ≥ 300 时再次评估。若 n ≥ 300 后 AUC 跌回 < 0.68，判负。

### 6.2 序贯检验 / 多重比较校正意图

本实验与 C-013 共享 fresh 样本池，存在**结论交叉污染**风险：

- 若 C-013 先触发上线 → 本实验的基线（生产 `t005v3_draw_detector.pkl`）会变化 → **本实验基线须用 C-013 定案后模型重跑**（2026-10-13 补钉）；
- 若本实验先触发上线 → C-013 的混合协议前提（`p_draw` 分布）会变化 → C-013 须重跑；
- 多重比较至少声明 **Bonferroni 校正意图**：若同时评估 4 个 ratio 候选 vs 基线，名义 α=0.05 应校正为 α/4=0.0125；本实验登记时声明此意图，具体是否执行 Bonferroni 取决于 fresh n ≥ 300 时的实际并行情况。
