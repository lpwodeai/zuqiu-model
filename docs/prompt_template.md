## 一、模板使用说明

### 1.1 使用场景

| 场景 | 使用方式 |
|------|----------|
| 新会话开始 | 复制完整模板作为系统提示词 |
| 阶段切换 | 更新【当前阶段标识】部分 |
| 任务完成 | 更新【已完成优化项清单】和【历史调整记录】 |
| 性能变化 | 更新【性能指标基准值】 |

### 1.2 更新规则

1. **每次任务完成后必须更新**：已完成项清单、历史调整记录
2. **每次性能测试后必须更新**：性能指标基准值
3. **每次阶段切换时必须更新**：当前阶段标识、待办事项列表
4. **关键参数变更时必须更新**：关键参数配置
5. **每一项优化完成、失败或中止时必须更新**：change_log.md、optimization_log.md，以及受影响的决策、记忆、阶段和专项文档；文档同步完成前不得标记为已完成

- 会话ID和时间戳
- 本次会话完成的任务
- 关键决策和代码变更

```
新会话开始
    ↓
读取提示词模板
    ↓
更新当前阶段标识
    ↓
注入到会话上下文
    ↓
开始执行任务
    ↓
任务完成后更新模板
    ↓
记录变更日志（change_log.md）
    ↓
更新优化日志（optimization_log.md）
    ↓
生成会话快照
```
