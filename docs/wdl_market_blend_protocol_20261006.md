## 冻结决策清单（TL;DR）

```
定位     校准对齐（模型 p_draw 贴近 WDL 市场），非预测增益，非 v5 转正必要条件
锚点     WDL 市场（wdl_history 去水，0.2502），沿用 C-009 赔率源/去水口径；
         不锚比分对角带（0.2371）。t-24h + noon 双锚点监控
机制     p_draw' = γ·p_draw + (1−γ)·mkt_draw；home/away 比例重归一
γ 公式   γ = clamp(0.4/|bias_train|, 0.2, 0.6)   [bias_train 取 fresh-150 之前数据]
         当前预估 γ≈0.30（bias=1.3pp 时 0.4/1.3=0.308）
         适用上界: 预注册 0.30 仅在 bias ≤ 1.67pp 时残差 ≤0.5pp
         硬失败界: bias > 2.5pp 时 γ=0.2 下限也压不进闸门① → 协议退出（模型重建问题）
残差性质 钳位区间内残差恒 = 0.4pp（γ·bias），与 bias 实际值无关
触发     黄线 1.5pp → 月度复核升周度；红线 2.0pp（月度复核确认非单月噪声）
         → 强制启动；验证窗 = fresh-150（预注册后新积累 ≥150 场，不回收 A/B 实验用过的 88 场）
闸门 ×5  ① |bias|≤0.5pp（全窗+EVAL 双窗）② WDL RPS 不退化 ③ 网格 RPS 不退化
         ④ top5≥0.46 且 top1 不下降 ⑤ TG/大小球边缘 RPS 不退化
红线     EVAL-peek 选型一律作废（C-012 B-dynamic β=0 陷阱）
Kill     bias 回落 ±1pp 内 / top1 命中率先被主线解决 / 出现新市场重定价漂移
层级     现在只做策略层（暴露 mkt_draw 字段）；模型层混合仅在红线触发后
```

## 2. 目标与定位（Q1）

- **动机是校准对齐，不是预测增益。** B 双臂已证 ΔRPS≈0（噪声级），本文档不承诺任何 RPS/命中率提升。若任何实验环节出现「预期提升」的措辞，视为违背本文档。
- **可选优化，非必做项。** +1.3pp 在 ±2pp 容差内，不是 v5 转正否决项（否决项 = top1 10.6% vs 19.1%、skill -0.125）。
- **本质声明：** 若走到模型层且闸门①要求 γ≤0.38，语义上等于平局维度约 70% 市场化、模型保留 30% 声音。在 B 实验已证模型平局无可测增益的前提下，这是诚实的定位，文档与报告均按此措辞，不包装为「模型增强」。

## 3. 公式与继承链（Q4）

### 3.1 混合公式与重归一

```
p_draw' = γ·p_draw + (1−γ)·mkt_draw
p_home' = p_home · (1−p_draw')/(1−p_draw)
p_away' = p_away · (1−p_draw')/(1−p_draw)
```

模型 p_draw（C-010 全窗口径 0.2628）> 市场（0.2502，冻结锚点），混合压低 p_draw → home/away 吸收释放质量 → 需验证 WDL argmax 在平局边界附近是否翻转（闸门②覆盖）。

### 3.2 下游继承链（影响清单）

```
p_draw' 变化
  ├─ WDL 落库值直接改变 → 闸门②（WDL RPS/argmax）
  ├─ λ 反演（solve_lambda_core 二分）重算 → λ_h/λ_a 漂移
  │    ├─ TG 大小球边缘连带扰动 → 闸门⑤（B 实验未测过，新增）
  │    └─ λ 二分边界：极端 p_draw' 需检查反演收敛（风险 8.2）
  ├─ v5 网格 IPF 平局边缘 → 平局带自动继承 p_draw'（C-011 已证钉死机制，
  │    大概率直接继承，实验时须做 B0 式保真验证：混合后网格平局带 vs p_draw' 逐场一致）
  └─ T-005 走水概率（C 路径网格聚合）受网格连带 → 观察项，不设闸门
```

### 3.3 锚点声明（Q5）

锚 WDL 市场（0.2502），不锚比分对角带（0.2371）——拉到对角带会制造系统性「永远卖平局」的价值信号，属策略取向而非校准。**代价**：混合后模型 vs 比分对角带仍残留 ≈+1.0~1.3pp，该部分永久定性为「市场口径价差」，报告口径不再计为模型偏差。

## 5. 选型悖论解决方案（文档核心）

### 5.1 悖论回顾

C-012 B-dynamic：VAL 窗无漂移 → VAL RPS 随 β↓ 单调变差 → 预同意选型规则必然选回 β=1.0 → 闸门 FAIL。**结论：γ 不能由窗口数据选，只能预注册。**

### 5.2 预注册公式

```
γ = clamp(0.4 / |bias_train|, 0.2, 0.6)

bias_train = 混合公式偏差（模型 p_draw 均值 − WDL 市场 mkt_draw 均值），
             在 fresh-150 验证窗**之前**的全部配对场次上测量
0.4 = 0.5pp 闸门目标 × 0.8 安全余量
```

- 残差性质：钳位区间内 γ·bias = 0.4pp 恒成立，与 bias 实际值无关。
- **公式陷阱备忘**（防止回归）：不能写成 `1 − 0.5/|bias|`——该式在 bias=1.3pp 时给出 0.615→钳位 0.6→残差 0.78pp FAIL，与闸门自相矛盾（C-20261006-013 评审中实际踩过）。
- g 口径（odds 保持比缩放）已**删除**：不可独立验算，且推导者自验时算错过一次（0.93 实际过冲至 −0.55pp 边际 FAIL；精确归零需 g≈0.958）。只保留线性 γ 口径。

### 5.3 适用上界与硬失败界

- **适用上界**：预注册 γ=0.30 仅当 bias ≤ 1.67pp（0.3×1.67=0.50）时过闸门①。触发时若 bias 超上界，按公式重推（bias=2.0 → γ=0.20，恰在钳位下限）。
- **硬失败界**：bias > 2.5pp 时 γ=0.2 下限残差 >0.5pp，混合机制数学上不可能过闸门① → 协议退出，问题定性为 WDL 模型重建，不属校准。

### 5.4 EVAL-peek 红线

任何在验证窗上看 bias/RPS/top1 调整 γ（或任何参数）的结果**一律作废**，无论指标多好看。C-012 B-dynamic β=0 的「EVAL RPS -0.0129、top1 翻倍」即此陷阱的实例。

## 6. 评估协议

- **双窗**：γ 推导窗（fresh-150 之前）→ 验证窗（fresh-150 ≥150 场）。
- **双基准**：vs WDL 盘平局隐含（主锚点）、vs 比分对角带（参考，残差定性为市场口径价差）。
- **五闸门**（全部预注册，验证窗上一次性判定）：

| # | 闸门 | 阈值 |
|---|---|---|
| ① | 平局带偏差 vs WDL 市场（全窗 + EVAL 双窗） | ≤0.5pp |
| ② | WDL RPS / argmax 不退化（混合直接改 WDL 落库值，上游闸门） | ΔRPS ≤0.005 且 argmax 命中不降 |
| ③ | 网格 RPS 不退化 | ΔRPS ≤0.005 |
| ④ | top5≥0.46 且 top1 不下降（容差 -0.005） | — |
| ⑤ | TG/大小球边缘 RPS 不退化（λ 反演连带，B 实验未测） | ΔRPS ≤0.005 |

- 任一退化 → 如实报告退化幅度，不接线；闸门①过但 ②~⑤ 任一退化 → 回退接受现状（+1.3pp 在容差内）。

## 7. 样本量与时间线

- 验证窗：fresh-150（预注册生效后新积累的 ≥150 场配对场次，**不回收** A/B 实验反复消费过的 88 场）。
- 分联赛结论需 ≥30 场/联赛；本次协议不做联赛级 γ（样本不支持），分联赛仅作观察项。
- 统计功效备忘（C-012 教训）：n=31 时偏差 SE≈2.2pp，处于噪声主导区；n=150 时 SE≈1.0pp，0.4pp 残差仍属「方向性证据」而非「精确估计」——报告措辞需匹配。
- 积累速率：≈3 场/天（08-22~09-21 攒 88 场）→ fresh-150 约 7~8 周。**触发评估预计 2026-11 中下旬**，以实际配对数为准。

## 9. 触发条件与 Kill Criteria

### 9.1 时序

| 阶段 | 动作 |
|---|---|
| 现在（shadow 期间） | ① 策略层：暴露 mkt_draw 字段（价值 = 下游消费者，**非监控前提**）；② 监控任务：**月度复核**全窗 bias（wdl_history 历史表、C-009 同口径，t-24h/noon 双锚）+ fresh-150 样本计数；③ 本文档冻结，D1~D5 不再改动 |
| 黄线（bias ≥1.5pp） | 月度复核升**周度复核**，确认是否趋势 |
| 红线（bias ≥2.0pp 且月度复核确认非单月噪声） | **强制启动**混合实验：按公式重推 γ（fresh-150 之前数据）→ 冻结 → fresh-150 上五闸门一次性判定 |

### 9.2 永不跑 / Kill

- bias 长期回落 ±1pp 内 → 混合无必要，协议归档
- top1 命中率先被主线解决（v5 转正瓶颈移除后优先级重排）
- 出现新的市场重定价漂移（市场口径本身不稳定时，混入市场 = 引入新噪声）
- bias > 2.5pp（硬失败界，转 WDL 模型重建议题）
