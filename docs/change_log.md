## 一、变更日志说明

### 1.1 适用范围

本日志记录以下类型的变更：

| 变更类型 | 说明 | 示例 |
|----------|------|------|
| 代码变更 | 修改Python/JavaScript源代码 | 修改函数逻辑、新增功能 |
| 参数变更 | 修改模型参数、配置参数 | max_depth从10改为6 |
| 配置变更 | 修改config.yaml、环境配置 | 新增配置项 |
| 数据变更 | 修改数据库结构、数据迁移 | 新增表、修改字段 |
| 依赖变更 | 修改package.json、requirements | 新增/升级依赖 |
| 文档变更 | 修改关键文档 | 更新硬性规则 |

### 1.2 记录原则

1. **必须记录**：每次代码/参数/配置变更都必须记录
2. **及时记录**：变更完成后立即记录，不得延迟
3. **完整记录**：包含变更前后的具体内容和原因
4. **可追溯**：每条记录可关联到具体的提交/文件

### 1.3 变更ID规则

```
格式：C-YYYYMMDD-NNN
- C：变更（Change）
- YYYYMMDD：日期
- NNN：当日序号（001开始）

示例：C-20260724-001
```
